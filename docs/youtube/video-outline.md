# Video outline

Working title: **I Built My Business Website Using OpenAI Codex, AI Skills and MCP**

1. Business problem: a brand site connecting business owners, technical readers and YouTube viewers.
2. Architecture: Next.js static export, strict TypeScript, Tailwind and MDX; explain why no CMS/database is needed.
3. Skills: show project-scoped frontend-design, content-authoring and website-qa; explain frontmatter and discovery.
4. MCP: show the local config and a real successful Microsoft Playwright MCP navigation, not just installation.
5. Build: tour the homepage, solutions, concept projects and responsive navigation.
6. Review: compare initial missing SVGs and weak contrast with corrected diagrams and labels.
7. Blog: demonstrate unpublished MDX in local preview, code highlighting/copy, filters and TOC.
8. Testing: show actual Playwright output, draft exclusion and Lighthouse results with caveats.
9. Deployment preparation: show out/, Cloudflare settings and the owner checklist; do not claim a deployment happened.
10. Final demo: distinguish implemented functionality from contact/video/content awaiting owner input.

## Recording checklist

Use an isolated browser session and close unrelated tabs. Hide account details, tokens, filesystem usernames and any private repository data. Record the production build and local editorial build separately. Never upload the preview export. Capture 375px mobile and 1440px desktop, keyboard navigation and a genuine 404. Re-run commands for a recording rather than presenting documentation as live execution.
