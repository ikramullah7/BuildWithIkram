# BuildWithIkram

A business and technology website built with Next.js App Router, strict TypeScript, Tailwind CSS and repository-authored MDX. Hosted on Cloudflare Pages at https://buildwithikram.pages.dev. The site exports static files with no project database or server backend; Web3Forms delivers contact enquiries.

## Development

Use Node.js 24 and npm.

```sh
npm ci
npm run dev
```

Open http://localhost:3000. To check the deployable output:

```sh
npm run check
npm run build
npm test
```

`npm run build` generates and validates `out/`. `npm run serve` serves that export locally. `npm run preview` includes unpublished articles for local editorial review; never enable `CONTENT_PREVIEW` on Cloudflare.

## Configuration and content

- `src/config/site.ts`: public origin, email, social links and public Web3Forms key.
- `.env.example`: optional build-time environment settings. `NEXT_PUBLIC_SITE_URL` overrides the default origin; `NEXT_PUBLIC_WEB3FORMS_ACCESS_KEY` overrides the configured public form key.
- `content/blog/`: MDX articles. Drafts are excluded from production routes, listings and sitemap.
- `content/projects/projects.json` and `content/videos/videos.json`: project and video records.
- `src/app/` and `src/components/`: pages and shared UI.

Preserve the static export architecture. The empty-article sentinel generated by Next.js is removed by `scripts/verify-export.mjs`; do not replace it with a draft route. Fonts are self-hosted, with their required licence in `src/assets/fonts/OFL.txt`.

The contact form submits directly from the visitor’s browser to Web3Forms. The public key identifies the recipient registered with that service; no mail password or additional Cloudflare service is needed. The owner reports that local submission works. Inbox receipt and the deployed form still need confirmation. The privacy page discloses external processing and needs owner review.

The About copy, three labelled project concepts, two draft demonstration articles and empty video catalogue need owner-approved content before being presented as real experience or published work.
